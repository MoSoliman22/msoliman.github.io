PROJECT 01 · FEATURED

HR Management System

A full-stack HR management application built in Oracle APEX, managing 110+ employee records across 27 departments and 19 job roles. Includes an interactive dashboard with animated KPI counters and live charts, a native org chart with drill-down employee profiles, role-based access control, a custom authentication scheme, and a fully custom CSS theme replacing the default Oracle look.

  • Interactive dashboard with animated KPI counters, bar/pie charts, and real-time analytics
  • Full CRUD for Employees, Departments, and Jobs with joined SQL for readable data
  • Native org chart (hierarchical Tree region) with click-through employee profiles
  • Employee Detail page showing job history and direct reports
  • Custom authentication scheme with role-based authorization
  • Automated onboarding workflow: new hires trigger an n8n webhook that emails their manager via APEX_WEB_SERVICE + APEX_JSON
  • Fully custom, responsive UI theme
